# Tooling alternatives (automotive)

Commercial tools commonly used:

- Vector PREEvision (architecture / system design)
- IBM Rational Rhapsody (MBSE / SysML)
- Vector DaVinci Developer/Configurator (AUTOSAR configuration)
- Elektrobit EB tresos (AUTOSAR configuration)
- dSPACE SystemDesk / TargetLink

Open-source / community alternatives:

- Eclipse APP4MC (multi-core timing & mapping)
- Artop (AUTOSAR tooling platform, Eclipse-based)
- openMDM / openPASS (simulation & test data)
- PlantUML / Mermaid (lightweight architecture diagrams)
- SysML v2 open implementations

Our direction: build an open, text-first, AI-friendly "single truth" instead of
locking artifacts inside proprietary binary models.

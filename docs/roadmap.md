# Roadmap: complete automotive domain platform

Planned feature areas (iterative):

- UI tools: web/desktop editors for templates and ARXML
- Test tools: integration, system and HIL test runners
- Android support: Android Automotive (AAOS) integration
- Automotive Grade Linux (AGL) support
- S-core (safety core) support
- OpenBSW support
- Full AUTOSAR support (Classic + Adaptive)
- Custom stack support
- Semiconductor driver configuration (MCAL, complex drivers, board support)
- Virtual network and vehicle variants
- Requirements/design/test traceability
- CI/CD and release automation
